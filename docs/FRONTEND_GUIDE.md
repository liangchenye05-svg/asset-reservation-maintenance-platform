# 同源Web演示与V3接口

通过已启动的Spring Boot首页访问，不能双击HTML获得业务功能；不依赖Vue/React或npm生产构建。登录后sessionStorage保存当前标签页JWT，退出清本地凭据，不宣称服务器注销。

USER看设备、自己的预约与工单，提交预约/报修并在允许条件下取消；ADMIN维护设备、审批/拒绝、受理/完成维修，工作台以OPEN聚合待办。按钮隐藏不是权限保障，服务端仍检查角色和归属。

工单页调用/repair-orders/page，状态/设备/关键词与page/pageSize由服务端分页；全部状态省略status，切换筛选回第1页。旧/repair-orders数组兼容接口仍存在。设备目录使用/devices/page逐页收集授权目录关联名称，浏览器端设备搜索未升级为服务端搜索。

受理前调用maintenance-impact，展示尚未结束批准预约总数和最多100条预览；说明保留预约、人工协调。完成前刷新工单详情，manualReviewRequired为真时要求核对说明，失败保留输入且不自动重试写请求。

列表/详情直接使用historyComplete持续提示缺口，不根据历史数组为空推断。历史仅展示真实动作、操作者ID、时间和转义后的说明。缺快照人工完成只结束工单，设备保持现状，恢复暂停不解除；设备详情显示暂停，不提供强制恢复按钮。

页面有加载、空结果、失败重试、确认、表单校验和提交禁用；桌面与390px已有合成环境证据，最新匿名同步实际范围见[TESTING](TESTING.md)。无承诺跨刷新请求幂等、完整无障碍标准或全部浏览器矩阵。

docs/images的login/devices/reservations/admin四张JPEG均为旧版本历史预览，不能称V3最新界面。本轮不新增截图。未来若授权补拍，应在合成演示库复现新工单历史、核对提示和移动布局，逐张检查像素与元数据，不能拍日常真实数据。
