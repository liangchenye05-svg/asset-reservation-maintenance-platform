## 提交前只读审查

本节只提供审查命令，不提供整目录或全量暂存快捷命令。正式暂存、提交、设置remote和推送必须另行明确授权。

```powershell
git status --short --untracked-files=all
git diff --check
git diff --stat
git diff -- .gitignore README.md docs/FRONTEND_GUIDE.md docs/GITHUB_RELEASE.md
git diff --cached --name-status
git diff --cached
git log -3 --oneline
git check-ignore -v -- src/main/resources/application.properties target/classes/application.properties .idea/workspace.xml
git ls-files -ci --exclude-standard
```

`git diff` 默认不显示未跟踪文件内容，必须同时审阅 `git status` 列出的新文件。确认 `.gitignore` 不能替代对已跟踪文件的检查。
